# Awesome-Electronic-Data-Capture

## 顶级电子数据采集 (EDC) 平台生态系统

**精选 SaaS 产品与开源 GitHub 项目列表**
*聚焦临床试验数据采集、GCP 合规、电子病例报告表 (eCRF) 与 CDISC 标准*
**最后更新：2026 年 9 月**

本仓库追踪**电子数据采集 (EDC)** 领域的知名 **SaaS 平台**与**开源项目**。这些工具帮助临床研究团队、制药企业和 CRO 以符合 GCP、21 CFR Part 11 和 CDISC 标准的方式采集、管理和导出临床试验数据。

**示例**包括 Medidata Rave、Castor EDC、OpenClinica、REDCap、Oracle Clinical One、Clinion、TrialKit、Ennov、DATATRAK、Viedoc、Veeva Vault EDC、ClinCapture、MACRO EDC、Ennov Clinical、IBM Clinical Development、MACRO by Elsevier 和 Anju EDC（该领域的领先者）。

**开源重点**：EDC 领域拥有**成熟的开源生态**，这与许多企业软件类别形成鲜明对比。**REDCap** 已被 166 个国家 8,378 个活跃合作伙伴使用，约 380 万用户来自近 8,000 家机构 。**OpenClinica** 社区版和 **LibreClinica** 提供 GCP 合规的 EDC 能力，支持完整审计追踪、电子签名和 CDISC ODM-XML 导出 。本列表重点收录所有主要活跃的开源 EDC 项目。

欢迎贡献！提交 PR 以添加/更新条目。保持描述事实性，并链接到官方网站。

## SaaS/托管平台

- **[Medidata Rave](https://www.medidata.com/)**
  制药行业领先的 EDC 平台，广泛用于注册性临床试验。提供电子数据采集、数据管理、编码和 CDISC 导出能力，与 Medidata 临床云生态深度集成。

- **[Castor EDC](https://www.castor edc.com/)**
  面向学术和研究者发起试验的轻量级 EDC。提供**Castor Essentials**（入门级，按使用付费）和 **Castor for Impact**（资助研究项目）。支持 I–IV 期试验、观察性研究和患者注册，提供无代码表单构建器，合规声明涵盖 21 CFR Part 11、GDPR 和 HIPAA 。

- **[OpenClinica](https://www.openclinica.com/)**
  全球领先的开源临床试验软件，提供社区版（免费自托管）和企业版（商业托管）。功能涵盖 EDC、ePRO、eCRF、eTMF 和 CDMS，支持完整的 GCP 合规能力 。

- **[REDCap](https://projectredcap.org/)**
  由范德堡大学创建的研究电子数据采集平台，**非营利机构通过 REDCap Consortium 免费使用** 。截至 2026 年中，拥有 166 个国家 8,378 个活跃合作伙伴，约 380 万用户来自近 8,000 家机构 。支持调查、数据采集、CDISC 导出和移动数据采集。

- **[Oracle Clinical One](https://www.oracle.com/)**
  云端临床数据管理平台，提供 EDC、数据管理和试验管理能力。Oracle 报告 CRO Atorus Research 在约四周内为基因治疗研究配置了 Oracle Clinical One EDC 。

- **[Clinion](https://clinion.com/)**
  AI 驱动的 EDC 和临床试验管理平台。提供电子数据采集、ePRO、随机化和试验管理，专注于中端市场和新兴市场。

- **[TrialKit](https://www.trialkit.com/)**
  基于云的临床研究平台，提供 EDC、ePRO 和 eConsent。以其灵活性和可配置性著称。

- **[Ennov](https://www.ennov.com/)**
  监管和质量套件中的 EDC 模块。提供文档管理、工作流和临床试验合规追踪。

- **[DATATRAK](https://www.datatrak.com/)**
  云端 EDC 和临床试验管理平台。提供电子数据采集、随机化和试验管理能力。

- **[Viedoc](https://www.viedoc.com/)**
  斯堪的纳维亚 EDC 平台，以现代化界面和用户友好性著称。提供电子数据采集、ePRO 和 CDISC 导出。

- **[Veeva Vault EDC](https://www.veeva.com/)**
  Veeva Clinical Suite 中的 EDC 模块，与 Veeva Vault CDMS 集成。提供电子数据采集和数据管理，与 Veeva 生态系统无缝连接。

- **[ClinCapture](https://www.clincapture.com/)**
  经临床验证的开源 EDC 软件（商业支持版）。提供电子数据采集、ePRO 模块、CTMS 集成和 CDISC 转换。

- **[MACRO EDC](https://www.elsevier.com/)**
  Elsevier 的 EDC 平台。提供电子数据采集、数据管理和 CDISC 导出，支持云端或本地部署 。

- **[IBM Clinical Development](https://www.ibm.com/)**
  IBM 的临床数据管理平台。提供 EDC、数据管理和 CDISC 能力，适用于大型制药和 CRO。

- **[Anju EDC](https://www.anjusoftware.com/)**
  临床数据管理平台。提供电子数据采集、ePRO 和试验管理，专注于肿瘤学和罕见病研究。

## 开源 GitHub 项目

- **[LibreClinica](https://github.com/reliatec-gmbh/LibreClinica)**
  OpenClinica 的社区驱动后继者。提供所有 GCP 合规临床试验所需功能：基于网络的电子表单 (eCRF) 带版本管理、简单和复杂字段验证、完整审计追踪和电子签名、双人数据录入支持、差异笔记和源数据核查 (SDV)、CDISC ODM-XML 导入、导出为 CDISC ODM-XML/TSV/Excel/SPSS/SAS。支持 OpenRosa API 后端，用于与 **ODK 生态系统集成以进行移动数据采集（如 ePRO 和 eCOA）** 。**LGPL-3.0**，Java 技术栈（OpenJDK 11、Tomcat 9、PostgreSQL 16）。版本 1.4.0（2025 年 7 月）。已用于德国癌症联盟 (DKTK)、亚琛大学医院、WHO 欧洲儿童肥胖监测倡议等机构 。

- **[clinicedc](https://github.com/clinicedc)**
  基于 Django 的多站点纵向临床试验数据管理框架。提供一套 Python 模块，用于构建 EDC/eSource 系统，处理知情同意、计划数据采集、质量保证、试验监测、报告、不良事件、临床事件分级、数据导出和审计 。源代码在 GitHub 上公开发布，最新试验有可在本地构建运行的演示。**GPL-3.0**。已用于哈佛 T.H. Chan 公共卫生学院、博茨瓦纳-哈佛艾滋病研究所合作项目、伦敦卫生与热带医学院和利物浦热带医学院等机构的 NIH 资助试验 。包含 119 个仓库，包括 `edc-qol`（EQ-5D 生活质量工具）和 `edc-he`（健康经济学模型）。

- **[OpenDataCapture](https://github.com/DouglasNeuroInformatics/OpenDataCapture)**
  由 Douglas NeuroInformatics 开发的开源电子数据采集平台，用于管理远程和现场临床工具。提供 98 个 star，本周活跃更新 。适合需要远程患者数据采集的神经信息学研究。

- **[COSMOS](https://github.com/at2e19/SCTU_COSMOS_DQDV_Shiny)**
  面向 FAIR 和 GCP 对齐的临床试验单元基础设施，专为学术临床和多组学试验数据设计。整合自动数据质量与验证“信任层”与关系型 SQL schema，通过 R Shiny 应用实现程序化和交互式数据访问。**GPL-3.0** 许可 。

- **[GNU Health](https://github.com/gnuhealth/gnuhealth)**
  GNU 项目的自由/开源健康与医院信息系统。提供医院管理、电子病历、实验室、药房和流行病学模块。**GPL-3.0**，Python 技术栈。**注意**：GNU Health 是 HIS（医院信息系统）工具，而非专门的 EDC 工具 。

- **[OpenEMR](https://github.com/openemr/openemr)**
  最流行的开源电子健康记录和医疗实践管理解决方案。**ONC 认证**（门诊 EHR），2026 年 2 月版本 8.0.0 获得认证。功能包括完全集成的电子健康记录、实践管理、排程、电子账单、电子处方和患者门户。**GNU GPL**。**注意**：OpenEMR 是 EHR/实践管理工具，而非专门的临床试验 EDC 。

- **[OpenMRS](https://github.com/openmrs/openmrs-core)**
  开源医疗记录系统，专为资源受限环境设计。模块化架构，强大的 HL7/FHIR 支持。**注意**：OpenMRS 是 EMR 工具，而非专门的 EDC 。

### 其他强开源选项

- **EDC 专用**：**LibreClinica**（OpenClinica 后继，GCP 合规）、**clinicedc**（Django，多站点纵向试验）。
- **FAIR 数据基础设施**：**COSMOS**（FAIR/GCP 对齐，R Shiny 交互式访问）。
- **远程数据采集**：**OpenDataCapture**（远程和现场临床工具管理）。
- **重要区分**：**GNU Health**、**OpenEMR** 和 **OpenMRS** 是 EHR/EMR/HIS 工具，**并非专门的临床试验 EDC 工具** 。它们可以用于临床数据管理，但缺乏 EDC 特有的功能（如 CDISC ODM 导出、eCRF 版本管理、SDV 工作流）。

**构建自定义系统的框架**：结合 **LibreClinica** 作为核心 EDC 平台（GCP 合规、CDISC 导出、ODK 集成），**clinicedc** 用于 Django-based 多站点试验框架，**COSMOS** 用于 FAIR 数据仓储和验证，**OpenDataCapture** 用于远程临床工具管理。添加 **PostgreSQL** 用于持久化，**ODK** 生态系统用于移动数据采集。

## 免责声明

- 这是一个**社区精选**列表——并非详尽无遗，也不构成认可。
- EDC 系统处理敏感的临床试验数据；确保符合 21 CFR Part 11、GCP、HIPAA 和 GDPR 等适用法规。
- **开源现实**：EDC 领域拥有**成熟的开源替代方案**。**REDCap** 是学术研究的实际标准，拥有庞大的全球用户群 。**LibreClinica** 是 OpenClinica 的活跃社区后继者，提供完整的 GCP 合规能力 。**clinicedc** 已被多个 NIH 资助试验用于生产环境 。然而，开源 EDC 需要机构 IT 或数据管理能力进行安装、托管和维护——这是自托管的权衡 。对于需要供应商托管、专业服务和验证支持的大型注册性试验，商业平台（Medidata、Veeva、Oracle）仍然是主流选择。
